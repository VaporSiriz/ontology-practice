# 온톨로지 강의 목차

이 강의는 온톨로지를 실제로 만들기 전에 개념을 먼저 정리하기 위한 자료입니다. 각 회차는 앞 회차를 전제로 합니다.

| 회차 | 주제 | 핵심 질문 |
|---|---|---|
| [01](01-what-is-ontology.md) | 온톨로지란 무엇인가 | 온톨로지는 무엇을 "명세"하는가? |
| [02](02-core-concepts.md) | 핵심 구성 요소 | 클래스, 개체, 관계, 속성, 공리는 각각 무엇인가? |
| [03](03-related-concepts.md) | 비슷한 개념과의 차이 | 택소노미, 시소러스, 지식 그래프, 데이터베이스 스키마와 무엇이 다른가? |
| 04 (예정) | 표현 언어와 추론 | RDF, RDFS, OWL은 무엇을 표현하고 무엇을 추론하는가? |
| 05 (예정) | 구축 방법론 | 도메인 범위를 정하는 것부터 인스턴스 작성까지 어떤 순서로 하는가? |
| 06 (예정) | 실습: 작은 온톨로지 만들기 | Protégé로 직접 만들고 검증하기 |

## 공통 예시 도메인

모든 회차는 같은 예시 도메인을 씁니다. 도서관입니다.

- 책(Book), 저자(Author), 회원(Member), 대출(Loan)
- 책은 저자가 썼다, 회원은 책을 대출했다, 대출은 기한이 있다
